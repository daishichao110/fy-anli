# 指南针代码工作室官网 - UI/UX 设计规范文档 (v3 极致高质感版)

## 1. 视觉设计理念 (Modern High-End Studio Aesthetic)

### 1.1 告别单调黑白，重塑高质感 UI 审美
- **拒绝单纯死黑/死白**：采用兼具工程沉稳感与现代化科技审美的 **Slate Blue / Ice White 层次色系**。
- **色彩调号**：
  - 主色调：渐变靛蓝 (`linear-gradient(135deg, #4F46E5, #06B6D4)`)
  - 卡片表面：高级冰白半透明玻璃 (`rgba(255, 255, 255, 0.85)` / `#FFFFFF`)
  - 背景基底：优雅柔和的雪青浅灰 (`#F1F5F9`) 与 渐变网格微发光背景 (`#E0E7FF` / `#EEF2FF`)
  - 文字阶梯：深沉墨青 (`#0F172A`) > 灰蓝 (`#334155`) > 亚光灰 (`#64748B`)
- **微交互与质感**：
  - 悬浮卡片微向上提升 6px，伴随 `0 12px 30px -4px rgba(79, 70, 229, 0.15)` 柔和光晕与边框高亮。
  - 图标：使用 Lucide 矢量图标系统。

### 1.2 联系方式重构 (Dedicated Contact Architecture)
- **去除重复堆砌**：移除过往重复贴在各板块的冗余微信条，保证主界面干练整洁。
- **专属集中呈现**：在 **Header 按钮**、**Hero 核心 CTA**、**专属【联系我们/需求评估】模块**及**弹窗 Modal** 中集中呈现官方微信 `free11092025`，配备一键复制与扫码/添加引导。
