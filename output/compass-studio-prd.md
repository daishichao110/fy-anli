# 指南针代码工作室官网 - PRD 产品需求文档

## 1. 产品概述
- **产品名称**：指南针代码工作室官方网站 (Compass Code Studio Official Site)
- **入口文件**：`index.html`（根目录下）
- **商业目标**：面向中小型企业、创业团队、个人站长及外包需求方，打造极具技术公信力、交付透明感与高满意度的软件定制开发官网。
- **核心定位**：专注高保真系统落地、微信小程序开发、企业级 Web SaaS 系统研发及 UI/UX 重构。

---

## 2. 目标用户与核心痛点

| 用户角色 | 核心需求 | 痛点 | 官网应对解法 |
|:---|:---|:---|:---|
| **创业者 / 线下门店老板** | 快速上线小程序/预约系统，需要能直接看演示 | 怕外包公司只吹不练，成果与预想差距大 | 50 个真实高保真案例在线演示 + 手机模拟器体验 |
| **企业 IT / 项目经理** | 定制专业后台系统/SaaS，关注代码质量与架构 | 怕二次开发困难、代码垃圾、隐藏费用 | 透明化工程质量标准 + 100% 源码交付承诺 + 标准 API |
| **技术外包采购负责人** | 寻找长期稳定靠谱的技术团队 | 交付延期、沟通低效、售后无门 | 5 步敏捷交付流程透视 + 半年质保保障 + 在线估算器 |

## 3. 功能模块规划与需求细节

### 模块 1：导航栏与 Header (Header Navigation)
- **品牌 Logo**：指南针图形徽章 + "指南针代码工作室" + "Compass Code Studio"。
- **主导航菜单**：
  - 首页 (Home)
  - 50+ 案例大厅 (Portfolio Hub)
  - 核心服务 (Services Matrix)
  - 工程质量 & 交付承诺 (Engineering & Warranty)
  - 在线预算估算 (Project Cost Estimator)
  - 交付流程 (Workflow)
  - 关于我们 (About Us)
- **核心 CTA 按钮**：【预约免费需求评估】（触发 Modal 弹窗）

### 模块 2：Hero 视觉信任区 (Hero Section)
- **主标题**：精准代码 · 稳健交付 · 商业级系统高保真落地
- **副标题**：指南针代码工作室为您提供全栈软件定制服务，50+ 涵盖生活服务、美业、宠医、企服的商业级可演示系统，开箱即用，全量源码交付。
- **信任数据指标 (Trust Metrics Counter)**：
  - `50+` 独立商业系统案例
  - `100%` 源码全量交付
  - `99.2%` 按时交付率
  - `0` 隐形增项收费
- **快速动作区**：
  - 主按钮：【浏览 50+ 商业案例大厅】
  - 次按钮：【在线需求估算】

### 模块 3：50+ 商业案例大厅 (Case Portfolio Hub)
- **案例源**：直接绑定 `deploy_html/01-car-wash.html` ~ `50-recycling-waste-collection.html`。
- **8 大主流分类 Tab 过滤**：
  1. 全部案例 (All Case Studies - 50)
  2. 生活与服务预约 (Life & Booking - 洗车/自习室/茶室/家政/移动洗车/私厨)
  3. 休闲文娱与体育 (Entertainment & Sports - 棋牌/琴房/健身房/剧本杀/户外/滑雪)
  4. 美业与健康管理 (Beauty & Wellness - 理发/美甲美睫/产后理疗/皮肤管理/瑜伽/按摩)
  5. 宠物经济与服务 (Pet Services - 宠医/洗护/陪遛/配种领养/殡葬)
  6. 共享租赁与体验 (Rental & Economy - 露营装备/无人机相机/服装/玩具绘本/奢侈品回收)
  7. 现场活动与社群 (Event & Community - 展会门票/同城二手/校友会商会/活动直播)
  8. 企服与法务工业 (Enterprise & Industrial - 企业报修/法律咨询/私域商城/施工质检/废品回收)
- **动态检索与标签过滤**：按关键词实时过滤，按【热度推荐】、【行业分类】、【系统类型】筛选。
- **案例卡片（Case Card）**：
  - 显示案例编号（例：`CASE #01`）、案例名称、行业分类标签、关键功能点（如：智能时段预约 / 实时叫号 / 移动支付）。
  - 操作按钮 1：【在线预览】（弹出高保真全屏/手机桌面 Mockup 弹窗）。
  - 操作按钮 2：【新标签页体验】（直接跳转 `deploy_html/xx.html`）。

### 模块 4：案例高保真在线预览模态框 (Interactive Preview Modal)
- **模拟器视角切换**：
  - 📱 手机端适配模式 (375x812 移动视角)
  - 🖥️ 电脑端宽屏模式 (100% 容器视角)
- **动态沙盒 iframe 嵌入**：无缝加载对应 `deploy_html/xx.html`。
- **案例技术参数侧边栏**：显示适用行业、核心模块、建议部署环境、搭配小程序/Web方案说明。

### 模块 5：核心服务体系 (Services Matrix)
1. **微信小程序与移动端研发**：原生 / Uni-app / Taro 跨端开发，适配 iOS/Android/微信/支付宝。
2. **企业级 Web SaaS & 后台管理系统**：React / Vue / Node.js 现代栈，权限控制、数据大屏、报表导出。
3. **高保真原型 UI/UX 设计与重构**：消除旧系统拖沓视觉，打造符合现代化工业级审美的交互体验。
4. **技术咨询与运维架构保障**：提供服务器环境部署、自动化 CI/CD 搭建及代码审计。

### 模块 6：工程质量与去AI味标准 (Engineering Standards)
- **高标准代码守则**：拒绝“AI拼贴感”代码，严格遵循模块化、高复用、语义化 HTML5 与现代 CSS 变量规范。
- **全量源码交付承诺**：代码无加密、无授权锁、无后门、支持自主二次开发。
- **严格安全审计**：SQL 参数化查询、XSS/CSRF 基础防护、JWT/Session 身份鉴权机制。

### 模块 7：交互式项目预算在线估算器 (Project Cost Estimator)
- **交互式点选步骤**：
  1. 选择项目类型（小程序 / 企业官网 / 后台SaaS / 综合平台）
  2. 勾选所需核心功能模块（用户鉴权 / 在线支付 / 预约调度 / 地图定位 / 导出来数据大屏等）
  3. 选择开发周期与保障级别（标准开发 / 紧急加急 / 深度定制保障）
- **实时结果计算**：动态估算出参考价格与大致工期，并支持生成【需求评估清单】，直接复制或带入联系表单！

### 模块 8：标准化敏捷交付流程 (5-Step Workflow)
1. **01. 需求诊断与快速评估**（24小时内响应，明确功能边界）
2. **02. 原型确认与UI规范锁定**（高保真交互走查，避免频繁变更）
3. **03. 敏捷开发与前端先行**（可视界面优先展示，开发进度透明）
4. **04. 质量门禁与全流程测试**（功能、兼容性、性能与安全走查）
5. **05. 上线部署与半年质保保障**（提供源码、技术文档与半年免费质保，Bug 承诺 2 个工作日内修复）

### 模块 9：常见问题解答 (FAQ Section)
- 关于源码归属、交付周期、二次开发、服务器与域名配置、售后保障等 6 核心问答。

### 模块 10：需求评估与联系弹窗 (Consultation Modal & Footer)
- 提供便捷的【提交需求单】表单：姓名/称呼、联系电话/微信、需求简述、项目预算区间。
- 官方微信、邮箱、响应承诺（1小时内快速回应）。

## 4. 非功能需求与验收标准
1. **去AI味视觉要求**：
   - 杜绝炫目低质紫色渐变，采用现代化 Slate/Zinc/Indigo 冷色系专业大厂审美。
   - 使用 Lucide 矢量图标，禁用 Emoji 作为功能图标。
   - 排版讲究留白、网格对齐、高对比度微交互。
2. **单页高性能原生加载**：
   - 使用 Vanilla HTML5/CSS3/JavaScript (ES6+)，无冗余打包框架依赖，确保 `index.html` 打开速度极致流畅。
3. **响应式兼容**：
   - Perfect Mobile (iOS/Android) 及 Desktop (1920px/1440px/1280px) 完美自适应。
4. **案例数据动态联动**：
   - 50 个 `deploy_html` 文件路径精准映射，点击无报错、预览顺畅。
